# Academic Manager

## Overview
Academic Manager is a Java-based console application designed for educational institutions.  
It supports two types of users: **students** and **teachers**, each with role-specific functionalities.

Students can manage course sections and view grades, while teachers can manage assignments and evaluate student performance.  
The application is built using **object-oriented programming (OOP)** principles and features user authentication, modular design, and interactive command-line navigation.

---

## Features

### Student Features
- Enroll in available course sections  
- Drop enrolled sections  
- View grades for assignments and exams  

### Teacher Features
- Manage student grades (add, edit, delete)  
- View all assigned grades  
- Create, update, and remove assignments  

### General Features
- **User Authentication** (ID & password stored in CSV files)  
- **Interactive Console Menus** for easy navigation  
- **Data Persistence** using external file storage
